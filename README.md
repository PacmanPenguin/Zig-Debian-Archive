This is an unofficial Zig repository with deb files I created from the official Zig binaries at https://ziglang.org/download/. 
I have versions 0.14.1, 0.15.2, 0.16.0, and 0.17.0 in this repository. 

Note: Currently, these packages are only compiled for x86_64 compatible installations and have been tested on Debian 12 and 13.
